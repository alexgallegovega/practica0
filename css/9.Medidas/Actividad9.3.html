Este es un párrafo de ejemplo con bastante texto para comprobar cómo funciona la altura mínima y máxima. Vamos a añadir más contenido para que el texto ocupe varias líneas y así el contenedor intente crecer más de lo permitido. Cuando el contenido supere la altura máxima establecida, el párrafo ya no crecerá más y aparecerá la barra de desplazamiento. Seguimos añadiendo más texto para asegurarnos de que supera claramente el límite establecido en el CSS y podamos ver el efecto correctamente.
